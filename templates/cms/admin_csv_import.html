CSV Format Guide

The first row of your CSV file must contain column headers. Use the following columns:

COLUMN TYPE DESCRIPTION
headlineRequiredContent headline text
slugRequiredContent slug identifier
entry_dateOptionalDate (YYYY-MM-DD), defaults to today
entry_timeOptionalTime (HH:MM), defaults to current time
fb, yt, ig, threads, tt, linkedin, bsky, dm, redditAt least 1Platform URL link
sponsorOptionalExisting sponsor name
memberOptionalUsername of member (defaults to uploader)
commentOptionalNotes or comments
